# Dados

O corpus não é versionado. Para baixá-lo:

```bash
python src/baixar_corpus.py
```

O script baixa `machado.zip` do repositório de dados do NLTK (github.com/nltk/nltk_data) e extrai em `data/raw/machado/`. Os romances usados ficam em `data/raw/machado/romance/marm01.txt` a `marm10.txt`, em codificação Windows-1252.

Os textos são de Machado de Assis (1839 a 1908), em domínio público.
